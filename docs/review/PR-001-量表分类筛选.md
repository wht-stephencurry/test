## 二、为什么要做

老师作业要求「以现有功能为主线，另开分支开发子功能」。选这个子功能的原因是：
1. 直接复用已有的 `scale.category` 字段，**零数据迁移**；
2. 输出可精确断言（认知功能 3 条、运动与跌倒 3 条、不存在分类 0 条）；
3. 不传参数时行为与主线完全一致，能同时验证**新功能可用**与**老功能不回归**。
