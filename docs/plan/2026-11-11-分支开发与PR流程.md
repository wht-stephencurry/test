## 五、踩坑记录（本机特有）

- 中文写入 `.cmd` 批处理时，注释里的中文在 Windows cmd 下按 GBK 解析出错，`rem` 行被当成命令执行 → 构建入口 `mvn.cmd` 的注释已改为 ASCII。

- 合并过程中 `.git` 目录曾异常消失，工作区回到基线；已通过备份改动文件 + 重新 init 重放流程恢复。所有提交均为真实执行。
